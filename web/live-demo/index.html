Deterministic conversation runtime

GVYA compiles explicit conversation source into a portable .gvya brain. The runtime stays deterministic, inspectable, bounded, and host-controlled — no generative model is required to run the bot.

GVYA is multilingual. This demo uses English and Persian as two sample languages to demonstrate that capability.
