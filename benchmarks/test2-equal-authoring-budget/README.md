# GVYA Comparator Test 2 — Equal Authoring Budget

A frozen three-way offline benchmark of **GVYA**, **ChatScript 14.1**, and **AIML 2.0 / Program-Y 3.6**.

The test gives every system the same fictional product brief and exactly **115 user-language evidence rows**, while allowing idiomatic engine-specific authoring. See `METHODOLOGY.md` for the budget definition and freeze order and `RESULTS.md` for the complete result and failure cases.

Headline: GVYA produced the most held-out positive coverage (**35.83%**) and the highest strict all-turn count (**44.67%**); ChatScript had the strongest near-domain rejection (**86.7%**). AIML produced **13.33%** positive coverage in this corpus.
